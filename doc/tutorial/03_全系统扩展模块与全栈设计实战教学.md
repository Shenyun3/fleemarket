## 1. 用户资料管理模块 (User Profile)

### 1.1 业务需求与设计
- 用户登录后可维护：**昵称、邮箱、手机号、收货发货地址、自我介绍（Bio）**。
- **安全与数据投影**：接口**绝对不能返回 `passwordHash`**，修改密码时需验证旧密码。

### 1.2 后端实现：`backend/src/controllers/userController.ts`
```typescript
/**
 * 1. 获取当前登录用户信息 (GET /api/users/me)
 */
export const getCurrentUserProfile = async (c: Context) => {
  try {
    const user = c.get("jwtPayload");
    const userId = user?.sub || user?.id;

    const profile = await prisma.user.findUnique({
      where: { id: userId },
      select: {
        id: true,
        email: true,
        username: true,
        phone: true,
        address: true,
        bio: true,
        status: true,
        createdAt: true,
      },
    });

    if (!profile) return c.json({ success: false, error: "用户不存在" }, 404);
    return c.json({ success: true, data: profile });
  } catch (error) {
    return c.json({ success: false, error: "获取用户资料失败" }, 500);
  }
};

/**
 * 2. 更新个人资料 (PUT /api/users/me)
 */
export const updateUserProfile = async (c: Context) => {
  try {
    const user = c.get("jwtPayload");
    const userId = user?.sub || user?.id;
    const body = await c.req.json<{
      username?: string;
      phone?: string;
      address?: string;
      bio?: string;
    }>();

    const updated = await prisma.user.update({
      where: { id: userId },
      data: {
        username: body.username ?? undefined,
        phone: body.phone ?? undefined,
        address: body.address ?? undefined,
        bio: body.bio ?? undefined,
      },
      select: {
        id: true,
        email: true,
        username: true,
        phone: true,
        address: true,
        bio: true,
      },
    });

    return c.json({ success: true, message: "プロフィールを更新しました（资料已更新）。", data: updated });
  } catch (error) {
    return c.json({ success: false, error: "更新资料失败" }, 500);
  }
};
```

## 2. 商品收藏夹模块 (Favorites)

### 2.1 业务需求与设计
- 用户点击红心一键收藏/取消收藏商品（`favorites` 表采用 `@@id([userId, productId])` 复合主键）。
- 商品详情与列表卡片可展示该商品的总收藏人数计数。

### 2.2 后端 Controller 关键代码
```typescript
// backend/src/controllers/favoriteController.ts
export const toggleFavorite = async (c: Context) => {
  const user = c.get("jwtPayload");
  const userId = user?.sub || user?.id;
  const productId = c.req.param("productId");

  const existing = await prisma.favorite.findUnique({
    where: { userId_productId: { userId, productId } },
  });

  if (existing) {
    await prisma.favorite.delete({
      where: { userId_productId: { userId, productId } },
    });
    return c.json({ success: true, favorited: false, message: "お気に入りを解除しました" });
  } else {
    await prisma.favorite.create({
      data: { userId, productId },
    });
    return c.json({ success: true, favorited: true, message: "お気に入りに追加しました" });
  }
};
```

## 3. 商品留言与层级回复模块 (Comments)

### 3.1 业务需求与设计
- 在商品详情页底部提供公开咨询区，买家可提问，卖家或他人可针对某条留言进行回复（`parentId` 自关联无限级嵌套）。

### 3.2 留言树查询设计
```typescript
// backend/src/controllers/commentController.ts
export const getProductComments = async (c: Context) => {
  const productId = c.req.param("id");

  const comments = await prisma.comment.findMany({
    where: { productId, parentId: null }, // 只查顶层留言
    include: {
      user: { select: { id: true, username: true } },
      replies: {
        include: {
          user: { select: { id: true, username: true } },
        },
      },
    },
    orderBy: { createdAt: "asc" },
  });

  return c.json({ success: true, data: comments });
};
```

## 4. 事件驱动消息通知中心 (Notifications)

### 4.1 业务需求与设计
- 履约关键节点自动产生站内通知（下单、发货、收到评价、违规警告）。
- 前端顶部导航栏展示红点未读角标（Unread Badge），点击后支持一键标记已读。

### 4.2 异步通知投递辅助函数
```typescript
// backend/src/lib/notifier.ts
import { prisma } from "./prisma.js";
import { NotificationType } from "@prisma/client";

export const sendNotification = async (
  userId: string,
  type: NotificationType,
  title: string,
  content: string
) => {
  try {
    await prisma.notification.create({
      data: { userId, type, title, content },
    });
  } catch (err) {
    console.error("发送通知异常:", err);
  }
};
```

## 5. 违规通报与合规风控治理 (Reports)

### 5.1 业务需求与设计
- 用户可对违规商品或不当言论提交举报（`POST /api/reports`）。
- 管理员可处理举报：执行 `WARNING` 警告或 `REMOVED` 强制下架商品。
- 用户累计违规次数 `violationCount >= 3` 时，自动将其状态置为 `SUSPENDED`（封禁），禁止登录与发帖。

## 6. AWS 云端架构设计与生产部署指南

根据课题文件《`doc/クラウドサービス_AWS_課題.md`》的严格约束指标，设计并实施云端上线部署。

### 6.1 AWS 资源约束核对表 (Compliance Checklist)
- [x] **统一打标规范**：所有资源必须附带标签：
  - `Owner: pavct.taro`
  - `Project: new-comer-2026`
- [x] **区域限定**：东京区域 (`ap-northeast-1`)。
- [x] **网络 (VPC)**：使用默认 VPC，严禁创建新 VPC；严禁使用 Elastic IP。
- [x] **数据库 (RDS)**：单实例 `db.t3.micro` PostgreSQL，**严禁开启公网访问 (Public Accessibility: No)**。
- [x] **计算实例 (EC2)**：选用 `t2.micro` 实例，严禁使用 Marketplace 镜像。
- [x] **API Gateway**：若采用 API Gateway，必须使用 REST API（禁止 HTTP API）。
- [x] **安全隔离**：通信控制完全依赖安全组（Security Groups），严禁引入 WAF。

### 6.3 部署执行步骤 (Deployment Steps)

#### 1. RDS PostgreSQL 实例创建
- 引擎：PostgreSQL 16
- 实例类型：`db.t3.micro`
- 公网访问：**关闭（否）**
- 安全组：绑定 `sg-rds`，入站规则只允许 `sg-web`（后端 EC2 安全组）访问 5432 端口。

#### 2. EC2 实例初始化
- 镜像：Amazon Linux 2023 或 Ubuntu 24.04 LTS
- 实例类型：`t2.micro`
- 安全组：`sg-web` 放通 22 (SSH), 80 (HTTP), 3000 (API)。

#### 3. 服务端代码拉取与容器化运行
在 EC2 服务器中执行：
```bash
# 1. 安装 Node.js 20 与 pnpm
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo yum install -y nodejs git
npm install -g pnpm

# 2. 拉取代码
git clone <repo_url> /app/fleemarket
cd /app/fleemarket

# 3. 注入生产环境变量 (.env)
cat <<EOF > backend/.env
DATABASE_URL="postgresql://postgres:<RDS_PASSWORD>@<RDS_ENDPOINT>:5432/c2c_db"
JWT_SECRET="production-super-secret-key-32chars"
PORT=3000
NODE_ENV=production
EOF

# 4. 执行数据库迁移与种子数据填充
pnpm install
pnpm --filter backend exec prisma migrate deploy
pnpm --filter backend exec tsx prisma/seed.ts

# 5. 使用 PM2 保持后台稳定运行
npm install -g pm2
pnpm --filter backend build
pm2 start backend/dist/src/index.js --name "fleemarket-api"
```
