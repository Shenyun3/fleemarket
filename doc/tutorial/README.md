## 🎯 三大核心教学模块规划

### 1. [01_商品与元数据模块开发教学](./01_商品与元数据模块开发教学.md)
- **涵盖功能**：分类树（`Categories`）、标签元数据（`Tags`）、图片上传服务（`Upload`）、商品出品/修改/检索/下架（`Products`）。
- **学习重点**：
  - 无限级自关联分类树查询。
  - 多表级联创建（Prisma `nested create & connect`）。
  - 水平越权（IDOR）资源所有权校验。
  - 前端搜索面板、商品详情相册、多图上传组件与路由联动。

### 2. [02_订单交易与资金评价模块开发教学](./02_订单交易与资金评价模块开发教学.md)
- **涵盖功能**：订单生命周期（`Orders`）、模拟支付流转（`Payment`）、履约发货与收货、平台 10% 佣金结算（`Balance`）、买卖双方双向信用互评（`Reviews`）。
- **学习重点**：
  - 订单履约状态机设计（`RESERVED` ➔ `PAID` ➔ `SHIPPED` ➔ `DELIVERED` ➔ `COMPLETED`）。
  - 并发防超卖：数据库事务锁（`prisma.$transaction`）。
  - 资金计算精度与交易流水记录（`Decimal` 计算）。
  - 双向防刷互评约束（`@@unique([orderId, reviewerRole])`）。
  - 前端交易面板、物流单号录入弹窗、五星打分交互。

### 3. [03_全系统扩展模块与全栈设计实战教学](./03_全系统扩展模块与全栈设计实战教学.md)
- **涵盖功能**：用户个人中心资料修改（`Users`）、商品收藏夹（`Favorites`）、层级留言回复（`Comments`）、事件驱动通知中心（`Notifications`）、违规举报与合规治理（`Reports`）、AWS 云端部署实战（EC2, RDS, S3, VPC, Tagging）。
- **学习重点**：
  - 敏感数据脱敏投影与密码安全策略。
  - 树形评论回复自关联查询。
  - 事件驱动的通知投递机制。
  - 满足公司培训约束的 AWS 云端高可用架构落地。

## 💡 建议的学习与实操节奏

1. **先读懂数据流图**：在写代码之前，先看文档中的 Mermaid 时序图，弄清前端参数是如何一步步到达数据库的。
2. **后编写后端接口并测试**：先完成 Controller 和 Router，使用 Vitest 或 Bruno 接口测试工具把后端跑通。
3. **再组装前端组件**：编写 React 页面，利用 Axios 拦截器与状态管理完成界面与 API 的联调。
4. **最后核对安全边界**：测试未登录拦截、普通用户越权修改他人商品等异常场景。
