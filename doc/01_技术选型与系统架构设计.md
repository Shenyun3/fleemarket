# 01. 技术选型与系统架构设计说明书

## 1. 系统概述与设计目标

本项目为企业级 **C2C 二手跳蚤市场（Flea Market）Web 应用程序**，模拟真实的二手电商交易生态（涵盖用户认证、商品发布与多维检索、图片上传、无限级分类、订单交易流转、双向互评、平台抽成结算与内容风控等功能）。

### 核心设计目标
1. **高内聚低耦合分层架构**：清晰分离视图展现层、API 路由层、中间件鉴权层、业务控制层、数据访问层与持久化存储层。
2. **端到端类型安全（End-to-End Type Safety）**：前后端统一采用 TypeScript 开发，结合 Prisma ORM 与 DTO 规范，实现从数据库表结构到前端界面的强类型保障。
3. **数据权限与安全性（Security & AuthZ）**：严格防范未认证访问、垂直越权与水平越权（IDOR，Insecure Direct Object Reference），实施敏感信息脱敏与密码强哈希存储。
4. **云原生与可部署性**：适配 AWS 部署规范（兼容 VPC、EC2/ECS、S3 与 RDS 架构约束），支持自动化 CI/CD 流水线与独立集成测试。

### 2.1 后端技术栈决策

| 选型组件 | 采用技术 | 选型原因与架构考量 | 对比替代方案 |
| :--- | :--- | :--- | :--- |
| **运行时环境** | **Node.js (v20+ LTS)** | 拥有成熟的生态系统、高并发异步 I/O 能力以及全栈 TypeScript 统一语言支持。 | Bun / Deno |
| **Web 框架** | **Hono** | 1. **高性能与极低开销**：采用 RegExp 路由树，性能远超传统 Express；<br>2. **Web 标准规范**：基于标准 `Request` / `Response` / `Fetch API` 设计，未来无缝适配 AWS Lambda / Cloudflare Workers 等 Serverless 架构；<br>3. **TypeScript 原生支持**：类型推导极致友好，上下文（`Context`）类型扩展简便。 | Express (老旧庞大)<br>NestJS (抽象层过重) |
| **ORM 数据访问层** | **Prisma 7** | 1. **Schema 驱动开发**：单一 `schema.prisma` 驱动迁移、生成 TypeScript 类型；<br>2. **Prisma 7 驱动适配器**：采用 `@prisma/adapter-pg`，避免传统 Rust 引擎过载问题，精准复用原生 Node `pg` 连接池；<br>3. **安全查询构建**：原生防 SQL 注入，支持级联创建与原子事务 (`$transaction`)。 | TypeORM / Sequelize |
| **数据库** | **PostgreSQL 16** | 支持 ACID 事务、强约束外键、复杂 JSON 查询以及全文不区分大小写检索 (`mode: "insensitive"`)，完美契合电商金钱结算与交易状态机需求。 | MySQL / MongoDB |
| **认证与安全** | **JWT (`hono/jwt`) + `bcryptjs`** | 1. **无状态认证（Stateless）**：减轻服务端内存会话负担，水平扩展友好；<br>2. **盐值哈希加密**：单向不可逆加密，严格防止密码泄露；<br>3. **强密码校验规范**：强制 8~24 位，含大小写字母、数字与特殊字符。 | Session/Cookie |
| **自动化测试** | **Vitest** | 零配置支持 TypeScript 与 ESM，测试速度极快；采用真实 PostgreSQL 数据库进行集成测试（非 Mock），保证接口真实可靠。 | Jest |

## 3. 全局系统分层架构设计

系统遵循经典分层架构（Layered Architecture）原则，各层职责边界清晰，单向依赖：

```mermaid
flowchart TD
    subgraph ClientLayer["1. 表现层 (Presentation Layer - Frontend)"]
        UI["React 页面与组件 (Pages & Components)"]
        State["React State / Hooks (状态管理)"]
        APIClient["Axios 封装层 (Interceptors & Auth Token)"]
    end

    subgraph TransportLayer["2. 传输与路由层 (Transport & Routing Layer - Backend)"]
        Router["Hono 路由中心 (/api/auth, /api/products, /api/users 等)"]
        CORS["CORS 中间件 (跨域白名单控制)"]
        Static["Static 服务 (/uploads 静态资源映射)"]
    end

    subgraph SecurityLayer["3. 认证与权限层 (Security & Middleware Layer)"]
        JWTAuth["JWT 鉴权中间件 (Token 校验与 Payload 解析)"]
        ContextInject["Context 注入 (c.set('jwtPayload', ...))"]
        OwnershipCheck["所有权鉴权 (IDOR 防护: product.sellerId === userId)"]
    end

    subgraph BusinessLayer["4. 业务控制层 (Business Controller Layer)"]
        DTO["DTO 参数校验 (必填项、格式、正整数金额)"]
        BizLogic["业务编排 (状态流转、10% 佣金计算、密码校验)"]
        DataMask["数据脱敏投影 (排除 passwordHash 等敏感字段)"]
    end

    subgraph DataAccessLayer["5. 数据访问层 (Data Access Layer)"]
        PrismaClient["Prisma Client (类型安全查询生成器)"]
        TxManager["事务管理器 ($transaction 原子操作)"]
        CascadeHandler["级联关系维护 (Images / Tags / Category)"]
    end

    subgraph PersistenceLayer["6. 持久化存储层 (Persistence Layer)"]
        PostgresDB[("PostgreSQL 关系数据库")]
        DiskStorage[("本地磁盘 /uploads (AWS S3 适配接口)")]
    end

    UI --> State
    State --> APIClient
    APIClient -->|HTTP / JSON| Router
    Router --> CORS
    CORS --> JWTAuth
    JWTAuth --> ContextInject
    ContextInject --> OwnershipCheck
    OwnershipCheck --> DTO
    DTO --> BizLogic
    BizLogic --> DataMask
    BizLogic --> PrismaClient
    BizLogic --> DiskStorage
    PrismaClient --> TxManager
    TxManager --> CascadeHandler
    CascadeHandler --> PostgresDB
```

## 4. 端到端数据流转模型 (End-to-End Data Flow)

### 4.1 典型业务场景：用户发布新商品数据流

```mermaid
sequenceDiagram
    autonumber
    actor Seller as 卖家 (Browser)
    participant Page as ProductCreate.tsx
    participant Axios as Axios 拦截器
    participant Hono as Hono Router (/api/products)
    participant Mid as AuthMiddleware
    participant Ctrl as productController.createProduct
    participant ORM as Prisma Client
    participant DB as PostgreSQL (products / product_images)

    Seller->>Page: 1. 填写表单 (标题, 说明, 价格, 分类, 上传图片)
    Page->>Axios: 2. 触发 API 请求
    Note over Axios: 自动读取 localStorage.token<br/>添加 Header: Authorization: Bearer <Token>
    Axios->>Hono: 3. HTTP POST /api/products
    Hono->>Mid: 4. 执行 authenticate() 中间件
    Mid->>Mid: 5. 校验 Bearer Token 签名与有效期
    Mid->>Mid: 6. 提取 payload.sub (sellerId) 注入 c.set("jwtPayload")
    Mid->>Ctrl: 7. 放行进入 Controller
    Ctrl->>Ctrl: 8. DTO 强校验: 价格>0, 标题/分类非空, 至少1张图片
    Ctrl->>ORM: 9. 调用 prisma.product.create (级联插入 images, 关联 tags)
    ORM->>DB: 10. 执行 SQL INSERT INTO products + product_images
    DB-->>ORM: 11. 返回插入成功的持久化数据
    ORM-->>Ctrl: 12. 返回包含关联关系的 Product Entity
    Ctrl-->>Axios: 13. 返回 201 Created JSON { success: true, product }
    Axios-->>Page: 14. 收到响应，清除表单并跳转商品详情页 (/products/:id)
```
