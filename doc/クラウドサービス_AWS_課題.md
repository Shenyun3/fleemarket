# クラウドサービス_AWS_課題

バックエンド開発の演習と、フロントエンド開発の演習の成果物をAWS上で動作させてインターネットを介して使用できるようにしてください。
構成は自由とします。

## 制約事項

### 全般

- 全てのAWSリソースにタグをつけて、最終的にすべて削除できるよう管理してください
  - Owner: pavct.taro (IAMユーザー名)
  - Project: new-comer-2026 (固定値)
- カスタムドメインの設定はしないでください(Route53など)
- WAFは導入しないでください
- Lightsail, ElasticBeanstalkは使用しないでください
- 東京リージョン(ap-northeast-1)を使用してください

### S3

- S3に対するパブリックアクセスを許可しないでください

### VPC

- VPCは新しく作らないでください
- VPCはデフォルトVPCを利用してください
- サブネットを作る場合は小さめにしてください
- 通信の許可はネットワークACLではなくセキュリティグループを使用してください
- Elastic IPは使用しないでください

### EC2

- インスタンスはt2.microを使用してください
- マーケットプレイスは使用しないでください

### API Gateway

- REST APIを使用してください(HTTP APIは不可)

### RDS

- デプロイオプションは単一のDBインスタンスにしてください
- インスタンスはdb.t3.microを使用してください
- RDSに対するパブリックアクセスを許可しないでください

### Dynamo DB

- オンデマンドキャパシティを使用してください(プロビジョニングは不可)

## ヒント

### バックエンド

- APIサーバーを何のサービスで稼動させるか
  - EC2
  - Lambda
  - ECS
- データベースを何のサービスで稼動させるか
  - EC2
  - ECS
  - RDS
  - Aurora
  - NoSQLに変えてDynamoDB

### フロントエンド

- フロントエンドのコードを何のサービスでホスティングするか
  - EC2
  - ECS
  - S3
